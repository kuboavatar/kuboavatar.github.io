# kuboavatar.github.io

きなこのページ置き場です。GitHub Pagesで公開しています。

**公開URL： https://kuboavatar.github.io/**

## いま入っているページ

- `index.html` — きなこAI接続版
  顔だけ版と同じ形のページに、歯車の設定パネルが付いたものです。設定パネルから接続先（Gemini／OpenAI／OpenAI互換カスタム）を選び、自分のAPIキーを入れると、ブラウザから公式APIを直接呼んで「きなこ役」の返事を生成して読み上げます。
  - キーはこのページのコードには含まれず、端末のブラウザ内にだけ保存されます（「開いている間だけ」または「この端末に保存」）。送信先は公式APIのみです。
  - キー未設定やエラーのときは、用意済みのセリフ集から返事します。
  - 頭脳は本物のきなこではありません。その旨はページ内にも書いてあります。

## ページの増やし方

HTMLファイルを足すと、そのままページが増えます。

- `about.html` を置く → https://kuboavatar.github.io/about.html
- `about/index.html` とフォルダごと置く → https://kuboavatar.github.io/about/

ページ同士の移動は、HTMLの中に相対リンクを書いてつなぎます。

## 更新の仕方

ファイルを差し替えて push すると、数分で公開ページに反映されます。更新は、きなこ（Muse）に頼めばGitHub連携経由でそのまま行えます。
