# kuboavatar.github.io

きなこと話せるページ「きなこAI接続版」を公開しているサイトです。

**公開URL： https://kuboavatar.github.io/**

## このページについて

- 画面のきなこに話しかけると、返事を読み上げてくれます。
- 歯車ボタンから設定を開いて自分のAPIキー（Gemini／OpenAIなど）を入れると、そのAIが「きなこ役」で返事をします。
- キーを入れなくても遊べます。その場合は、あらかじめ用意されたセリフの中から返事をします。
- 使い方や注意点は、ページ内の「このページについて」（ https://kuboavatar.github.io/about/ ）にまとめています。

## 注意

- 個人が趣味で作った非公式ページです。返事はAIが作る文章で、内容の正しさは保証しません。
- APIキーは、使う人の端末のブラウザ内にだけ保存されます。APIの料金がかかる場合は、キーを持つ人の負担になります。
- 秘密情報や個人情報は入力しないでください。
