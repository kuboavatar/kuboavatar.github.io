# kuboavatar.github.io

きなこと話せるページ「きなこAI接続版」を公開しているサイトです。

**公開URL： https://kuboavatar.github.io/**

## このページについて

- 画面のきなこに話しかけると、返事を読み上げてくれます。
- 歯車ボタンから設定を開いて自分のAPIキー（Gemini／OpenAIなど）を入れると、そのAIが「きなこ役」で返事をします。
- キーを入れなくても遊べます。その場合は、あらかじめ用意されたセリフの中から返事をします。
- 使い方や注意点は、ページ内の「このページについて」（ https://kuboavatar.github.io/about/ ）にまとめています。

## 接続先とモデルの設定まとめ

### 接続先サービス（プロバイダ）

- **Gemini（Google）**：Google AI Studio のキーを使います。Flash 系と Gemma 系には無料枠があります。
- **OpenAI**：OpenAI のキーを使います（従量課金で、ChatGPT Plus とは別会計）。o 系・gpt-5 系などの新しいモデルにも対応しています。
- **Claude（Anthropic）**：Anthropic のキーを使います。
- **OpenAI互換（カスタム）**：下記の接続先プリセット、または任意の OpenAI互換エンドポイントに繋げます。

### カスタムの接続先プリセット

- **Ollama（ローカル・無料）**：`http://127.0.0.1:11434/v1`。キーは不要です。初回はモデルの読み込みに時間がかかるため、応答の待ち時間は最大120秒にしています。繋がらない時は、環境変数 `OLLAMA_ORIGINS` に `https://kuboavatar.github.io` を許可して Ollama を再起動してください。
- **LM Studio（ローカル・無料）**：`http://127.0.0.1:1234/v1`。キーは不要です。
- **Groq（無料枠）**：`https://api.groq.com/openai/v1`。キーは console.groq.com で取得します。
- **OpenRouter（無料モデルあり）**：`https://openrouter.ai/api/v1`。料金が0のモデルには、モデル一覧で「（無料）」と付いて先頭に並びます。
- **GitHub Models（無料）**：`https://models.github.ai/inference`。GitHub のトークンをキーとして使います。
- **Cerebras（無料枠）**：`https://api.cerebras.ai/v1`。キーは cloud.cerebras.ai で取得します。

### キーとモデルの扱い

- APIキーは接続先ごとに別々の入力欄があり、別々に保存されます。設定済みのキーは伏せ字で表示されます。
- 「有効なモデル一覧を取得」を押すと、そのキーで実際に使えるモデルを取り寄せてリストに入れます。取得した一覧はブラウザに保存され、次回もそのまま使えます。
  - OpenAI の一覧はチャット用モデルだけに絞り、日付付きの旧版は代表1つにまとめて、新しい順に並べます。
  - Gemini と Gemma は思考の扱いが違うため呼び分けています。思考メモの混入や日本語でない返事は、自動で別経路に再試行します。
- 料金が無料かどうかは API からは判定できません（目安：OpenAI／Claude は基本有料、Gemini は一部モデルに無料枠、OpenRouter は料金0のモデルが無料）。
- AI に繋がらなかった時は、理由が画面の小さい文字に表示され、セリフは「繋がらなかった」と伝える専用のものになります。

## 声について（VOICEVOX / AivisSpeech）

- 読み上げの声は設定で選べます。端末のブラウザの声のほか、自分のPCで動かしている VOICEVOX互換エンジン（VOICEVOX / AivisSpeech など）の声も使えます。
- エンジンの声を使う場合は、エンジン側でこのサイトからの接続を許可してください。
  1. エンジンを起動した状態で、ブラウザで設定ページを開きます（AivisSpeech： http://127.0.0.1:10101/setting ／ VOICEVOX： http://127.0.0.1:50021/setting ）。
  2. 「Allow Origin」に `https://kuboavatar.github.io` を追加します。
  3. エンジンを再起動します。
  4. このページの設定で「ローカルエンジン（VOICEVOX互換）」を選び、「接続して声のリストを取得」を押して話者を選びます。
- 声の合成は自分のPCの中で行われ、読み上げる文章が外部に送られることはありません。

## 注意

- 個人が趣味で作った非公式ページです。返事はAIが作る文章で、内容の正しさは保証しません。
- APIキーは、使う人の端末のブラウザ内にだけ保存されます。APIの料金がかかる場合は、キーを持つ人の負担になります。
- 秘密情報や個人情報は入力しないでください。
