# kuboavatar.github.io

きなこと話せるページ「きなこAI接続版」を公開しているサイトです。

**公開URL： https://kuboavatar.github.io/**

## このページについて

- 画面のきなこに話しかけると、返事を読み上げてくれます。
- 歯車ボタンから設定を開いて自分のAPIキー（Gemini／OpenAIなど）を入れると、そのAIが「きなこ役」で返事をします。
- キーを入れなくても遊べます。その場合は、あらかじめ用意されたセリフの中から返事をします。
- 使い方や注意点は、ページ内の「このページについて」（ https://kuboavatar.github.io/about/ ）にまとめています。

## 声について（VOICEVOX / AivisSpeech）

- 読み上げの声は設定で選べます。端末のブラウザの声のほか、自分のPCで動かしている VOICEVOX互換エンジン（VOICEVOX / AivisSpeech など）の声も使えます。
- エンジンの声を使う場合は、エンジン側でこのサイトからの接続を許可してください。
  1. エンジンを起動した状態で、ブラウザで設定ページを開きます（AivisSpeech： http://127.0.0.1:10101/setting ／ VOICEVOX： http://127.0.0.1:50021/setting ）。
  2. 「Allow Origin」に `https://kuboavatar.github.io` を追加します。
  3. エンジンを再起動します。
  4. このページの設定で「ローカルエンジン（VOICEVOX互換）」を選び、「接続して声のリストを取得」を押して話者を選びます。
- 声の合成は自分のPCの中で行われ、読み上げる文章が外部に送られることはありません。

## 注意

- 個人が趣味で作った非公式ページです。返事はAIが作る文章で、内容の正しさは保証しません。
- APIキーは、使う人の端末のブラウザ内にだけ保存されます。APIの料金がかかる場合は、キーを持つ人の負担になります。
- 秘密情報や個人情報は入力しないでください。
